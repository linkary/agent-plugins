# Quick Task 260425-t1z: Fix skills update repeatedly reporting updated skills

**Date:** 2026-04-25
**Status:** In progress

## Finding

Repeated update prompts happen when the same skill name is tracked under multiple repos. The central skill record has one current `source.url`, but `ap skills update` was scanning every repo's historical `repo.skills` list. If a stale repo contains a different skill with the same name, it is always reported as an update.

## Tasks

1. Filter repo scan skill names to the skill's current git source repo.
   - Files: `src/commands/skills/update.ts`
   - Verify: stale duplicate repo-skill entries are skipped before clone/compare.

2. Add regression coverage for duplicate skill names across repos.
   - Files: `tests/skills-update.test.ts`
   - Verify: update only uses the current source URL for the skill.

3. Run available checks.
   - Verify: `git diff --check`; `bun test tests/skills-update.test.ts` if Bun is available.
